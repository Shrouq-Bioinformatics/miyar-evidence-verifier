COMMON PROVIDER CONTRACT
==================================================

Every live provider must adapt to the new MIYAR EvidenceProvider interface.

Example conceptual interface:

interface EvidenceProvider {
  id: string
  title: string
  domain: string
  search(claim: Claim): Promise<EvidenceItem[]>
}

Evidence item:

{
  sourceTitle: string
  locator: string
  excerpt: string
  url: string | null
  metadata?: Record<string, unknown>
}

All providers must return normalized evidence into the existing
/api/verify/public pipeline.

==================================================

Each provider MUST be isolated.

Use:
- per-provider try/catch
- reasonable timeout
- empty evidence fallback

If evidence is unavailable:
return a valid verification result such as:

or:

needs_review

Do NOT crash the request.

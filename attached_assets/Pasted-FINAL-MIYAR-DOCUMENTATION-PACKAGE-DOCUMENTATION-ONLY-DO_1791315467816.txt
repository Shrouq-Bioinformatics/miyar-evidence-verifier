==================================================
4. THE SOLUTION
==================================================

Explain MIYAR's verification workflow:

1. User pastes existing Islamic content.
2. MIYAR extracts verifiable claims.
3. MIYAR identifies the relevant knowledge domain.
4. Claims are routed to the appropriate available source provider.
5. Evidence and source locator are retrieved.
6. MIYAR evaluates the relationship between claim and evidence.
7. The user sees:
   - claim
   - evidence status
   - source
   - locator
   - evidence excerpt
   - reason for the result

==================================================
NON-NEGOTIABLE PRODUCT DEFINITION
==================================================

مِعيار منصة لضمان جودة المحتوى الإسلامي قبل النشر.

The user already has Islamic content.

They paste it into MIYAR.

MIYAR:

1. preserves the original text
2. extracts checkable claims
3. identifies the type/domain of each claim
4. routes each claim to the correct approved source family
5. retrieves relevant evidence
6. evaluates whether the evidence really supports the claim
7. shows the result claim-by-claim
8. shows the source and locator
9. distinguishes supported claims from insufficient evidence, reference mismatch, or cases requiring human review

Core message:

"مِعيار لا يكتب المحتوى بدل المستخدم؛ بل يتحقق مما سيُنشر."

==================================================
DIRECT RENDERING — CRITICAL
==================================================

The flow must be exactly:

textarea
→ POST /api/verify/public
→ receive JSON
→ setResponse(json)
→ render result immediately

No:
save to DB

fetch result again
load session
redirect to results route

Use simple React local state:

const [content, setContent] = useState("")
const [loading, setLoading] = useState(false)
const [error, setError] = useState<string | null>(null)
const [result, setResult] = useState<VerificationResponse | null>(null)

On submit:

setLoading(true)
setError(null)

const response = await fetch("/api/verify/public", ...)

if (!response.ok) {
  show real service error
} else {
  const json = await response.json()
  setResult(json)
}

finally:
setLoading(false)

IMPORTANT:
Never clear result after successful setResult.

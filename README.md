# مِعيار | MIYAR

منصة عربية للتحقق من جودة المحتوى الإسلامي قبل النشر. تحلل مِعيار النص إلى
ادعاءات قابلة للتحقق، وتربط كل ادعاء بالدليل والمصدر وموضعه وسبب النتيجة.

> مِعيار لا يكتب المحتوى بدل المستخدم؛ بل يتحقق مما سيُنشر.

## المشكلة والحل

ذكر مرجع لا يثبت تلقائيًا الادعاء؛ فقد تكون الإحالة غير دقيقة، أو لا يكفي
الدليل، أو يكون نطاق المصدر أضيق من التعميم. وقد يكون التحقق اليدوي بطيئًا
ومتفرقًا. تجمع مِعيار عناصر التحقق في نتيجة واحدة واضحة وقابلة للتتبع، من دون
المبالغة فيما تثبته المصادر.

## كيف يعمل

1. يلصق المستخدم محتوى قائمًا.
2. يساعد الذكاء الاصطناعي على فهم النص واستخراج الادعاءات وتصنيف مجالها.
3. يوجّه النظام البحث إلى مزود متاح للمجال.
4. يسترجع الدليل وموضعه، ثم يقيّم صلته بالادعاء.
5. تعرض الواجهة الادعاء والحالة والمصدر والموضع والاقتباس وسبب النتيجة.

يدعم مِعيار استخراج عدة ادعاءات مستقلة من الفقرة العربية، بما في ذلك بعض الجمل المركبة، مع الحفاظ على سياق الإحالات مثل «هذه الآية» عند تحويل الادعاء إلى صيغة مستقلة قابلة للتحقق.

الذكاء الاصطناعي ليس مصدرًا علميًا. عند غياب دليل كافٍ لا تختلق مِعيار دعمًا،
والإحالة غير المطابقة لا تُصحح بصمت.

## المصادر

**متاحة في النسخة الحالية:**

- القرآن الكريم: نص Tanzil Simple Clean 1.1 وبيانات Tanzil للسور والآيات.
- التفسير: «المختصر في تفسير القرآن الكريم» عبر QuranEnc؛ ليس «جامع البيان
  للطبري».
- الحديث: سجلات مباشرة من صحيح البخاري وصحيح مسلم عبر HadithWeb/بوابة السنة في
  الرئاسة العامة للبحوث العلمية والإفتاء.
- السيرة: «السيرة النبوية لابن هشام» عبر الاسترجاع المعمول به من HadithWeb/Alifta.
  ورود النص في السيرة لا يثبت صحة حديث.

**قيد الربط وليست مزودات حية:** مختصر القدوري، كتاب السنة لعبدالله بن أحمد بن
حنبل، قاموس المحتوى الإسلامي/الجمهرة، وبينات.

## الإعداد والتشغيل

المستودع يستخدم `pnpm` ومساحات عمل. في Replit شغّل تدفقي العمل المسجلين
للواجهة وAPI؛ يزوّد توجيه المسارات الصفحة بـ`/` والخدمة بـ`/api`.

```sh
pnpm install
```

للتشغيل المحلي المنفصل، في طرفيتين:

```sh
PORT=8080 pnpm --filter @workspace/api-server run dev
```

```sh
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/miyar run dev
```

فحص صحة API مباشرة:

```sh
curl http://localhost:8080/api/healthz
```

يحتاج التحقق المدعوم بالذكاء الاصطناعي إلى `OPENAI_API_KEY` على الخادم فقط.
انسخ `.env.example` إلى إعداد محلي عند الحاجة، ثم أدخل القيم في Replit Secrets
أو البيئة المحلية؛ لا تضع قيمة سرية في Git. يحقن Replit قيم الخدمة `PORT` و
`BASE_PATH` في تدفقي العمل. خارج Replit، يلزم توجيه `/api/*` إلى API عند عرض
الواجهة محليًا؛ أوامر تشغيل الواجهة لا تضيف وكيل Vite لهذه المسارات.

## الفحوصات

```sh
pnpm --filter @workspace/api-server run typecheck
pnpm --filter @workspace/miyar run typecheck
pnpm --filter @workspace/api-server run test:providers
```

مجموعة مزودي المصادر تضم 24 اختبارًا. آخر تحقق في 2026-10-06: فحوص الأنواع
للخادم والواجهة ناجحة، الاختبارات 24/24، وفحص الصحة أعاد HTTP 200
`{"status":"ok"}`. نتائج الحالات التي جرى التحقق منها:

- اختبار آية النحل 90: «موثق».
- رقم إحالة البخاري غير الصحيح 999999: «تعارض في الإحالة».
- ادعاء الإجماع اعتمادًا على مختصر القدوري: «الدليل غير كافٍ»؛ المصدر غير متصل.

## البنية

- `artifacts/miyar/` — واجهة React وTypeScript وVite، مع صفحات التحقق والمصادر
  والسجل.
- `artifacts/api-server/` — خدمة Node.js وExpress وTypeScript، ومسارات التحقق
  ومزودو الأدلة واختباراتهم.
- `artifacts/api-server/data/tanzil-quran/` — نص القرآن وبيانات Tanzil
  للقراءة فقط.
- `artifacts/api-server/data/upstream-miyar/` — ملف ترخيص MIT ومعلومات منشأ
  تنفيذ QuranEnc المستورد.
- `artifacts/miyar-competition-demo/` — معاينة وفيديو المسابقة؛ الحقوق الخاصة
  بالمواد المقدمة تحتاج المراجعة قبل إعادة توزيعها.
- `docs/` — التوثيق التفصيلي وقائمة التسليم.

واجهات الخدمة: `POST /api/verify/public` و`GET /api/healthz`.

## الخصوصية والحدود

لا يوجد تسجيل دخول أو حساب مستخدم أو سجل تحقق محفوظ على الخادم. يحفظ السجل
اختياريًا في `localStorage` بمتصفح المستخدم على جهازه، ويتيح فتح نتيجة سابقة
وحذف سجل واحد أو مسح السجل؛ يحتفظ بحد أقصى 30 نتيجة. يُرسل نص التحقق إلى OpenAI
عبر الخادم لتحليله. لا تدخل معلومات شخصية أو سرية.

تعتمد النتيجة على المصادر المتاحة وصحة اتصالها ونطاق النص المسترجع. ليست كل
مجالات المصادر حية، وقد تتأثر الإتاحة بالشبكة. مِعيار لا تستبدل مراجعة المختص،
وقد تحتاج الحالات الملتبسة أو المركبة إلى مراجعة بشرية. أُجري اختبار استخدام
أولي محدود على مستخدمين اثنين؛ النتائج أولية ومحدودة ولا تُعمم.

## التراخيص وسلامة المستودع

نص Tanzil Simple Clean 1.1 مرفق مع إشعار CC BY 3.0 وشروط النسبة وعدم التغيير
وإدراج الإشعار والرابط؛ راجع `artifacts/api-server/data/tanzil-quran/README.md`.
بيانات XML تشير إلى `cc-by` من دون تحديد الإصدار في رأس الملف. شروط إعادة نشر
نصوص QuranEnc وHadithWeb/Alifta غير موثقة محليًا، كما أن حقوق شعار وصوت وصور
الفيديو المقدمة تحتاج تأكيدًا قبل النشر العام.

يتجاهل `.gitignore` ملفات البيئة والمفاتيح والبيانات المحلية والسجلات وملفات
البيانات الداخلية `.agents/` و`.local/`. لا يتضمن `.env.example` قيمًا سرية.

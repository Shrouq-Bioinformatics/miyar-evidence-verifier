# مِعيار

**مساحة لمراجعة الادعاءات وتتبع الأدلة قبل النشر**

## نبذة

مِعيار مساحة عمل تساعد فرق المحتوى والبحث على إجراء مراجعة أولية للادعاءات الإسلامية. يجمع ما عُثر عليه من أدلة ذات صلة، ويعرض إحالاتها ومقتطفاتها، وينظم مراجعة بشرية قبل اعتماد النتيجة للنشر. لا يصدر مِعيار فتوى ولا يحل محل المتخصص.

## المشكلة

قد يتداول محتوى إسلامي بإحالات غير واضحة أو ناقصة أو منسوبة إلى مصدر غير مناسب. ومراجعة الادعاء يدويًا عبر مصادر متعددة قد تستغرق وقتًا، خصوصًا عندما يحتاج المراجع إلى تتبع النص والإحالة والسياق.

## الحل

يجمع مِعيار بين استرجاع محلي لنص القرآن، واسترجاع محدد للتفسير عند طلبه، وبحث ويب مقيّد بنطاقات معتمدة. يعرض النتائج بوصفها مادة أولية للمراجعة، ولا يعتبر وجود اسم مصدر أو رابط وحده دليلًا على صحة الادعاء.

## كيف يعمل مِعيار؟

1. يرسل المستخدم ادعاءً أو سؤالًا مع سياق يساعد على فهم المقصود.
2. يسترجع النظام الأدلة المحلية ذات الصلة، ومنها آيات القرآن عند ملاءمتها.
3. عند طلب التفسير، يجلب التفسير للآيات المحددة من QuranEnc؛ ويوجّه البحث الخارجي إلى النطاقات المناسبة من القائمة المعتمدة.
4. يُعدّ تحليلًا أوليًا يستند إلى الأدلة التي استُرجعت فعلًا، أو يوضح حدود النتائج المتاحة عند غياب دليل مناسب.
5. يعرض الإحالات والمقتطفات وبيانات المصدر المتاحة، مع إبقاء أنواع الأدلة منفصلة.
6. يسجل مراجع مساحة العمل قرار المراجعة البشرية على الحالة؛ ولا يمنح دور المراجع مؤهلًا علميًا أو شرعيًا.

## أنواع المصادر الحالية

### القرآن الكريم

يتضمن التطبيق النص الكامل من **Tanzil Project — Simple Clean، الإصدار 1.1**، مع بيانات السور من Tanzil Quran Metadata، الإصدار 1.0. يغطي النص 114 سورة و6,236 آية مرقمة. يُعرض نص الآية كما ورد في الملف المصدر؛ وتُستخدم معالجة البحث داخليًا للمطابقة فقط.

### التفسير

عند طلب معنى آية محددة، يسترجع مِعيار بيانات التفسير من **QuranEnc** لطبعة **المختصر في تفسير القرآن الكريم**. هذا استرجاع لآيات محددة، وليس مجموعة تفسير محلية كاملة.

### البحث عبر نطاقات معتمدة

يُقيّد البحث الخارجي بهذه النطاقات:

- [dorar.net](https://dorar.net/)
- [binbaz.org.sa](https://binbaz.org.sa/)
- [alifta.gov.sa](https://alifta.gov.sa/)
- [binothaimeen.net](https://binothaimeen.net/)
- [iifa-aifi.org](https://iifa-aifi.org/)

### تغطية حديثية محلية محدودة

تتضمن النسخة سجلًا تجريبيًا محليًا واحدًا من صحيح البخاري (حديث 1) وسجلًا واحدًا من صحيح مسلم (حديث 55). هذه السجلات لا تمثل متنًا محليًا كاملًا لأي من الصحيحين. يوضح [سجل المصادر](docs/SOURCES.md) طريقة الإسناد والحدود.

## التحقق متعدد اللغات

يمكن معالجة الادعاءات المقدمة بالعربية والإنجليزية والفرنسية لأغراض الاسترجاع. تستخدم العربية المقدمة كما هي للبحث؛ ويمكن إنشاء استعلام عربي محدود للبحث عند إدخال الإنجليزية أو الفرنسية. تبقى نصوص الأدلة بلغتها الأصلية. لا يعني ذلك أن كامل واجهة المستخدم مترجم إلى اللغات الثلاث أو أن جودة الترجمة مقاسة علميًا.

## السلامة والموثوقية

- يقيّد البحث الخارجي بنطاقات محددة، ويفحص صلة النتيجة بالادعاء قبل إظهارها كدليل.
- ينشئ الخادم معرّفات الأدلة المسترجعة؛ ولا يُقبل للاستشهاد إلا معرّف دليل استُرجع فعلًا.
- لا يحوّل اسم كتاب أو مصدر أو رابط عام إلى دليل خاص بالادعاء.
- إذا لم يتوفر دليل مناسب، يمتنع التحليل عن تقديم نتيجة مدعومة ويوضح حدود ما توفر.
- يبقى التحليل الآلي الأولي منفصلًا عن قرار المراجع البشري.
- يتطلب تسجيل النتيجة المدعومة دليلًا مقبولًا مرتبطًا بالحالة وملاحظة مراجعة.
- أدوار المالك والمراجع صلاحيات داخل مساحة العمل، وليست إثباتًا لاعتماد أكاديمي أو شرعي.

لشرح الضوابط والحدود بمزيد من التفصيل، راجع [السلامة والموثوقية](docs/SAFETY.md).

## البنية التقنية

- الواجهة: React وTypeScript وVite.
- الخادم: Node.js وExpress وTypeScript.
- البيانات: PostgreSQL وDrizzle ORM.
- تسجيل الدخول: Clerk.
- الذكاء الاصطناعي والاسترجاع: خدمات OpenAI، مع استرجاع محلي للقرآن واسترجاع خاص بالمصادر.

## الاختبارات

في التحقق من هذا المستودع، نجح فحص الأنواع والبناء الكامل، ونجح 97 اختبار API لا يتطلب اختبار قاعدة البيانات، كما نجح اختبار التقييم الهندسي (1 من 1). يحتوي مجموع API على 98 حالة اختبار معرّفة؛ لم يُشغّل اختبار التكامل المصادق عليه لأنه ينشئ بيانات اختبار في قاعدة بيانات التطوير. هذه اختبارات هندسية وسلامة برمجية، وليست اعتمادًا شرعيًا أو دراسة دقة علمية مستقلة. التفاصيل في [ملخص الاختبارات](docs/TESTING.md).

## حدود النظام

- يعتمد الاسترجاع على المصادر المتاحة وقت الطلب؛ وقد يتغير توفر الخدمة أو نتائج البحث.
- ظهور إحالة خارجية لا يثبت وحده صحة الادعاء أو انطباق المصدر عليه.
- قد يتطلب التفسير الديني الدقيق أو السياق المتخصص مراجعة مؤهل مختص.
- تغطية صحيح البخاري وصحيح مسلم المحلية محدودة بسجل تجريبي واحد لكل كتاب.
- لم تثبت اختبارات المشروع دقة شرعية مستقلة أو اعتمادًا مؤسسيًا أو تغطية شاملة للمصادر.

## التشغيل محليًا

المتطلبات: Node.js 24 وpnpm.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

يمكن تشغيل الخادم والواجهة في نافذتين طرفيتين منفصلتين:

```bash
pnpm --filter @workspace/api-server run dev
```

```bash
pnpm --filter @workspace/miyar-evidence-verifier run dev
```

تحتاج الواجهة إلى الوصول إلى API على مسار `/api` من الأصل نفسه. خارج راوتر Replit، اضبط وكيلًا عكسيًا يوجّه `/api/*` إلى الخادم. لا يتصل تشغيل المنفذين المنفصلين تلقائيًا ببعضهما من دون هذا التوجيه.

### أسماء متغيرات البيئة

الأسماء التالية مستخدمة أو مدعومة في إعدادات التطبيق. لا تضع قيمها في ملفات عامة أو في المستودع:

| الغرض | أسماء المتغيرات |
| --- | --- |
| قاعدة البيانات | `DATABASE_URL` |
| تسجيل الدخول | `VITE_CLERK_PUBLISHABLE_KEY`, `VITE_CLERK_PROXY_URL`, `CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` |
| مزود الذكاء الاصطناعي | `AI_INTEGRATIONS_OPENAI_API_KEY`, `AI_INTEGRATIONS_OPENAI_BASE_URL`, `OPENAI_API_KEY` |

تُوفّر Replit متغيرات التشغيل الخاصة بقواعد البيانات في بيئة التطوير. أما التشغيل المحلي فيحتاج إعداد قاعدة بيانات تطوير ومزودي المصادقة والذكاء الاصطناعي المناسبين. استخدم مدير الأسرار أو متغيرات بيئة محلية غير متتبعة، ولا تُرسل بيانات شخصية أو سرية إلى التطبيق.

## English overview

Miyar is a workspace for preliminary evidence review before publication. It retrieves relevant material from a bundled Quran text, QuranEnc tafsir for selected verses, and a restricted set of external domains. Results are preliminary and require human review. Miyar does not issue fatwas or establish scholarly accuracy.

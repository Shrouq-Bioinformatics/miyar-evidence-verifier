# ملخص الاختبارات

يوضح هذا الملخص ما يمكن التحقق منه في مستودع مِعيار. الاختبارات الهندسية لا تقيس صحة الاستدلال الشرعي ولا تعادل دراسة دقة علمية مستقلة.

## ما تغطيه الاختبارات

تشمل الحالات التي شُغلت أو عُرّفت اختبارات لـ:

- استرجاع القرآن والتحقق من مراجع الآيات والفصل بين القرآن والتفسير.
- استرجاع QuranEnc، وفشل الخدمة أو البيانات غير المطابقة.
- تقييد نطاقات البحث والتحقق من الروابط والإحالات الخارجية وصلتها بالادعاء.
- منع الاستشهاد بمعرّفات أدلة لم تُسترجع، والامتناع عند غياب الأدلة المقبولة.
- معالجة الادعاءات العربية والإنجليزية والفرنسية لأغراض الاسترجاع.
- صلاحيات مساحة العمل، وإنشاء الحالات ومراجعتها، ومنع تعيين حالة مدعومة من إدخال العميل وحده.
- التعامل مع أخطاء مزود الذكاء الاصطناعي والبحث الخارجي.

يتضمن اختبار التكامل المصادق عليه تدفقات API مرتبطة بالمستخدم ومساحة العمل وقاعدة البيانات. لا يُعدّ هذا اختبار متصفح، ولم يُشغّل في هذا التحقق حفاظًا على قاعدة بيانات التطوير دون تعديل.

## اختبار التقييم وحدوده

اختبار التقييم الهندسي يتحقق من ضوابط مثل رفض الاستشهادات غير المدعومة ومنع الثقة غير المسندة. وهو اختبار برمجي لحواجز السلامة، وليس قياسًا للدقة الشرعية أو أداء الخبراء.

لم تثبت الاختبارات:

- دقة شرعية مستقلة أو اعتمادًا دينيًا أو أكاديميًا.
- تغطية كاملة للمصادر أو توافرها المستمر.
- جودة ترجمة علمية للادعاءات الإنجليزية أو الفرنسية.
- انطباق كل نتيجة ويب خارجية على الادعاء دون مراجعة بشرية للسياق.

## أوامر التحقق

```bash
pnpm run typecheck
pnpm run build
cd artifacts/api-server
mapfile -t tests < <(find tests -maxdepth 1 -type f -name '*.test.ts' ! -name '*integration*' | sort)
NODE_ENV=development node --experimental-strip-types --test "${tests[@]}"
```

يشغّل أمر مجموعة API الكاملة اختبار التكامل المصادق عليه أيضًا؛ لا تشغّله على قاعدة بيانات تطوير تحتوي بيانات مستخدمين إلا في بيئة اختبار مخصصة وبعد مراجعة أثره.
